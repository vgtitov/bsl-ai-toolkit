# Гайд по дизайну форм 1С: какой элемент выбрать и как расположить

Рекомендации для интерфейса «Такси»; для «Версия 8.5» см. рекомендации и методику перехода 1С на ИТС.
Источник: репозиторий [Oxotka/1CDesignGuide](https://github.com/Oxotka/1CDesignGuide) (MIT; статья на Инфостарт: https://infostart.ru/1c/articles/2167324/),
пересказано коротко, с примерами и картинками — в оригинале. Стандарты 1С по формам: https://its.1c.ru/db/v8std#browse:13:-1:11.
Порядок применения (типовая форма, новая форма, эксклюзивный интерфейс) — `form-layout.md`.

## Выбор элемента
| Задача | Элемент | Правила |
|---|---|---|
| вывести текст, подсказку | надпись (декорация) | точка в конце не нужна для одного предложения; не использовать вместо заголовка простого поля (теряется автофокус) и не для выравнивания (для этого свойства групп) |
| иллюстрация | картинка | из библиотеки картинок, не из файла |
| ввести значение | поле ввода | ширина под самое длинное значение; кнопка очистки (x), если значение необязательное (в отборах вместо неё флажок); подсказка ввода у необязательного поля; многострочное поле для строк длиннее 100 символов, заголовок сверху; повторно используемые значения (период, организацию) запоминать; одно возможное значение заполнять само, поле скрывать функциональной опцией; для составного типа не платформенный выбор типа, а отдельный |
| включить опцию | флажок | заголовок справа; опция простая, оба состояния понятны; без отрицаний в заголовке («Не проводить…»); сложная опция — переключатель |
| переключить состояние формы сразу | выключатель | действие мгновенное, без подтверждений; не больше 2–3 на странице |
| выбрать одно из 2–5 значений | переключатель | значение по умолчанию первым; для сложных значений — отдельные подсказки (два элемента на один реквизит); повторяющиеся слова в заголовок; действует на то, что справа и ниже; значений больше 5 — поле со списком |
| выбрать из 3–5 коротких значений, форма под ним перестраивается | тумблер | для двух значений не использовать (неясно, что выбрано); повторяющиеся слова в заголовок |
| открыть подчинённую или служебную форму | гиперссылка | осмысленный и достаточно длинный текст; без «здесь», «тут», «подробнее»; не две подряд; цвет не менять (кроме предупреждений); действия на форме гиперссылкой не выполнять |
| выполнить действие | кнопка | понятный заголовок, не короткий; кнопка с пометкой для команды над строкой списка; «без фигуры» только для нежелательных команд или когда кнопок слишком много; переход на другую форму кнопкой не делать |
| набор связанных строк | табличная часть | заголовок в одну строку; без заголовка, если колонка одна; последняя пустая колонка (без заголовка, только просмотр, растягивается по горизонтали) управляет шириной; заголовок колонки выровнен как значения (число справа) |
| вопрос или предупреждение | диалог | только для необратимого; чёткий вопрос и однозначные ответы; кнопка подтверждения повторяет действие; закрытие крестиком обрабатывать как `КодВозвратаДиалога.Отмена` |
| пояснить элемент | подсказка | разовая — по кнопке; про всю форму, если нужна нечасто, — сверху; для сложного реквизита — снизу; выделение (жёлтый фон, картинка) для важного; не навязчиво |

## Группы
- Заголовок обычной группы чаще не нужен; слово «Группа», которое добавляет платформа, из заголовка убрать, подсказки группы по умолчанию убрать.
- Направление `Горизонтально, если возможно` не использовать: результат зависит от ширины окна, ориентир — минимум 1280 × 768. Выравнивание прижимать свойством группы «Выравнивание элементов и заголовков», а не пустой декорацией.
- Выделение: сильное — полоса и отступ у подчинённых; обычное и слабое — крупный заголовок; обычное, если нужен больший отступ вокруг группы.
- Свёртываемая группа: для необязательного, что делает форму компактнее. Заголовок говорит, что внутри (кроме групп из одних команд и ссылок); снять отступ слева; не класть частое и обязательное; не ставить выше обычных групп.
- Всплывающая группа: осторожно, пользователь может её не заметить. Для необязательных и справочных реквизитов; значения показывать в заголовке; отображение управления «Картинка»; заголовок говорящий; частое и обязательное не класть.
- Условное оформление: одни и те же стили для одинаковых условий, мало разных цветов, видимость строк им не управлять.

## Расположение на форме
- **Шапка:** сверху вниз и слева направо по важности. Редко меняемое (организация, подразделение) справа, заполнять автоматически или запоминать; симметрия не нужна. Нижние поля не должны менять верхние: сначала контрагент, потом договор. Поле, меняющее форму (вид операции), самое первое. Скрывать лишнее функциональными опциями.
- **Подвал:** наименее важное и справочное — итоги; последними обычно комментарий и ответственный.
- **Команды формы:** основная кнопка в форме на весь экран — слева вверху («Провести и закрыть»), в модальной — справа внизу («ОК»). Одна кнопка по умолчанию на форме (если равнозначных несколько — все жирным шрифтом на золотом фоне RGB 255,255,0); при смене страниц назначать заново.
- **Командная панель:** собственные команды — источник команд «Форма» для стандартных команд объекта и «Глобальные команды командной панели формы» для глобальных (структура подчинённости, история изменений). Таблицу разбить на две — продублировать стандартные команды формы и отключить их в составе команд.

## Проверка программой
`1c-meta form lint` (группа `layout`) находит группы без заданного направления и слово «Группа» в показанном заголовке; остальное проверяет человек по скриншоту.
