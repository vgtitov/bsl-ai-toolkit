# Профиль стиля форм проекта — ШАБЛОН

Скопируй в `references/local/form-style-profile.md` и заполни. Общие правила компоновки: `form-layout.md`.
Значения бери из своих элементов стиля, не выдумывай; не подтверждённое помечай `[проверить]`.

## Где применяется
Какие формы (имена, вид) оформляются по профилю, какие нет (типовые формы, формы других контуров).

## Токены (элементы стиля)
| Роль | Имя элемента стиля | Значение | Где используется |
|---|---|---|---|
| цвет основной | | | шапка, акценты |
| цвет фона страницы | | | корневая группа |
| цвет белый / карточки | | | карточка, рамка таблицы |
| цвет шапки таблицы | | | `titleBackColor` колонок |
| цвет текста | | | заголовки карточек и колонок, строки |
| цвет подписи | | | подписи полей, подсказки |
| шрифт заголовка формы | | | шапка |
| шрифт заголовка карточки | | | карточка |
| шрифт подписи | | | подписи полей |
| шрифт шапки таблицы | | | заголовки колонок |
| шрифт таблицы | | | строки |
| шрифт подсказки | | | пустое состояние |

Нужного токена нет: заводи элемент стиля, значение по месту в форму не пиши.

## Кнопки
Общая картинка кнопки (имя, где лежит, размеры), правило для локализованных кнопок.

## Что НЕ переносим
Контуры или конфигурации, где оформление остаётся обычным и важна только компоновка.

## Эталонные формы
Имена форм, на которые равняться (шапка, фон, карточки, таблица).
