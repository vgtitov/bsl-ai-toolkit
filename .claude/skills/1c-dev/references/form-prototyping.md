# Прототип формы до разработки: Figma или HTML

Нужен для эксклюзивного интерфейса (режим 4 в `form-layout.md`) и для спорной компоновки новой формы. Для типовой
формы и обычной новой — не обязателен: достаточно `form-design-guide.md`.

## Что прототипировать
Только то, что 1С умеет: прямоугольные блоки, группы с отступами и заголовками, поля, таблицы с колонками, кнопки,
надписи, картинки из библиотеки. Скруглённые карточки, «чипсы» в ячейках, произвольные тени и анимации в 1С
не воспроизводятся: в прототипе их быть не должно.

## Figma
- Библиотека элементов под 1С: Figma-файл «Mitaa: 1C UI-kit (Unofficial, Community)» — https://www.figma.com/design/Nzvz5HURB7nRrniEuQCrOG/Mitaa--1C-UI-kit--Unofficial---Community-
  (неофициальный, из Community; перед использованием проверить лицензию и актуальность под вашу платформу и интерфейс).
- Прототип собирать из компонентов набора и по `form-design-guide.md`: шапка, группы, подвал, командная панель.
- Подключение к агенту — Figma MCP (официальный сервер Figma, `https://mcp.figma.com/mcp`, вход по OAuth от
  аккаунта разработчика, либо локальный сервер в десктопном приложении). Токены и вход вводит человек, не агент.
  Что отдают инструменты (контекст дизайна, скриншот, метаданные, переменные) и как они называются, сверять с
  версией сервера после подключения `[проверить]`.
- Файл без доступа по API агент прочитать не может: Figma рисует холст в браузере, текста на странице нет. Нужны MCP,
  выгрузка кадров (PNG) или описание блоков человеком.

## Из прототипа в форму
1. Список блоков прототипа → таблица «блок → элемент 1С и свойства» (`form-layout.md`, режим 4) или
   `form-design-guide.md` (режим 3).
2. Структура: EDT MCP (EDT) или `1c-meta form add-*` (Конфигуратор). Оформление: `1c-meta form set-style` токенами
   профиля проекта.
3. Каждому цвету и шрифту прототипа — токен профиля (`references/local/form-style-profile.md`). Нет токена —
   завести элемент стиля, значение по месту в форму не писать.
4. Сверка: скриншот формы рядом с прототипом; кнопки-картинки и скрытые командные панели смотреть в клиенте.
5. Расхождения с прототипом, которых 1С не позволяет, назвать в отчёте, не скрывать.

## HTML вместо Figma
Если Figma недоступна: локальный `.html` в папке задачи, блоки только из таблицы режима 4, открывается браузером.
