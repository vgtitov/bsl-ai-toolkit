# Компоновка и оформление управляемой формы: общие правила

Правила расположения и группировки элементов, одинаковые для любого проекта. Конкретные цвета, шрифты и имена
элементов стиля не здесь, а в профиле стиля проекта (`references/local/form-style-profile.md`, каркас:
`form-style-profile-template.md`). Нет профиля — оформление обычное, правила компоновки ниже всё равно действуют.

## Главные правила
1. **Оформление в свойствах формы, не в коде.** Цвет, шрифт, рамка, группировка задаются свойствами элемента
   (`1c-meta form set-style`), а не присваиванием `Элемент.ЦветФона` при открытии формы: форма в EDT остаётся
   голой, вид проверяется только запуском. Код формы отвечает за поведение.
2. **Цвета и шрифты ссылкой на элемент стиля** (`style:<Имя>`), не значением по месту (`rgb:…`, `face=…`).
   `1c-meta form lint` такие места находит. Значение токена задаётся один раз в самом элементе стиля.
3. **Сначала структура, потом стиль.** Группы и порядок строятся отдельно (`form add-group`, `add-table`, `move`,
   EDT MCP), оформление накладывается серией `set-style`. Структурные правки не вперемешку с ручным открытием формы.
4. **Каждый видимый заголовок на всех языках проекта** (группа, надпись, поле, колонка). Колонка без своего
   заголовка берёт синоним реквизита, и шапка таблицы выходит наполовину на одном языке.
5. **Проверка глазами.** Структуру и компоновку смотреть скриншотом формы после каждой правки; нестандартные
   кнопки-картинки и скрытые командные панели EDT рисует неверно, их проверять в клиенте 1С.

## Блоки формы → элементы и свойства
| Блок | Элемент и свойства |
|---|---|
| Страница (фон) | ОДНА корневая группа, всё содержимое внутри, включая шапку: `group=Vertical`, `united=true`, отступы по горизонтали `None`, по вертикали `Half` (зазор между карточками), растяжение в обе стороны. Фона у самой формы нет, фон только группой |
| Шапка | группа `AlwaysHorizontal`, `representation=WeakSeparation`, `united=true`, отступы `None`, растяжение по горизонтали; заголовок надписью, `autoMaxWidth=false`, `verticalAlign=Center` |
| Карточка | группа `Vertical`, `representation=WeakSeparation`, `showTitle=true`, `united=true`, растяжение по горизонтали |
| Ряд полей в карточке | ВНУТРЕННЯЯ группа `AlwaysHorizontal`, `representation=None`, `showTitle=false`, `verticalAlign=Bottom`. Саму карточку горизонтальной не делать: заголовок горизонтальной группы встаёт слева от полей |
| Поле | `titleLocation=Top`, `width` в `extInfo` |
| Таблица | `commandBarLocation=None`, если панель не нужна; `titleLocation=None`; колонки `horizontalStretch=false` с `width`; технические колонки (номер строки, идентификатор) `visible=false` |
| Подсказка, пустое состояние | надпись под таблицей, `autoMaxWidth=false`; текст по данным задаёт код (`НСтр`, все языки) |
| Кнопка | кнопка формы `representation=Picture`, `shapeRepresentation=None`, `picture` — общая картинка проекта; нижний ряд кнопок `AlwaysHorizontal` с `representation=None`, кнопка вправо — `groupHorizontalAlign=Right` |

## Ловушки
- Шапка отдельным корневым элементом рядом с группой-фоном растягивается независимо и выходит короче. Всё в одной корневой группе.
- Отступы `None` вместе с `united` у всех групп слепляют карточки, зазор даёт `verticalSpacing=Half` у страницы.
- Предпросмотр EDT не показывает SVG-кнопки (грузятся в рантайме) и рисует скрытые командные панели.
- Порядок и допустимые значения свойств движок берёт из таблицы по корпусу реальных форм. Незнакомое свойство `set-style` отклоняет, наугад не пишет.

## Какой формат чем делается
| Что | EDT (`Form.form`) | Конфигуратор (`Form.xml`) |
|---|---|---|
| Структура (группы, таблицы, колонки, страницы, команды, кнопки) | EDT MCP | `1c-meta form add-*`, `move`, `remove` |
| Оформление | `1c-meta form set-style` | `1c-meta form set-style` |
| Проверка | `1c-meta form lint` | `1c-meta form lint --checks titles` |

## Свой стиль проекта
Положи профиль в `references/local/form-style-profile.md` по шаблону `form-style-profile-template.md`: какие
элементы стиля есть в проекте и какой роли они соответствуют (заголовок, подпись, фон, шапка таблицы, кнопка).
Агент подставляет их в таблицу блоков выше и не придумывает значения. Правила компоновки профиль не отменяет.
