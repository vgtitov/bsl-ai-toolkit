# Карточка уровня

Короткая запись о человеке: по ней вы в следующем чате продолжаете, а не начинаете сначала. Пять-восемь строк, без оценок личности: только про работу с ИИ.

## Формат
```
Уровень: новичок | уверенный | разработчик (дата, по чему определено)
Типовая задача: ...
Умеет сам: ... (по дате)
Исправил сам: N раз, примеры
Слабое место: ... (одно)
Следующий шаг: ... (одна подсказка)
Метрики: задач без правок постановки X из Y; мини-задача без подсказок: результат (дата)
```

## Где живёт карточка
- **Claude с набором:** личный файл человека вне общего репозитория (например в личной папке, не в папке проекта под git) или личная память. Не клади карточку в общий репозиторий и не коммить. Читай в начале, обновляй в конце только после согласия человека.
- Поля «Типовая задача» и «Слабое место» пиши обобщённо («сводки для руководства»), без названий проектов, заказчиков и рабочих деталей.
- **Веб-Copilot без памяти между чатами:** человек хранит карточку у себя и вставляет её в начало чата, либо кладёт в пользовательские инструкции или инструкции своего агента (если такие настройки есть в вашей среде). Копировать карточку обратно в своё хранилище должен человек: попроси его в конце.
- В карточку не пишите имена людей, названия заказчиков, данные рабочих баз.

## Как обновлять
В конце каждой работы покажи человеку новые строки и спроси «сохраним так?». Исправил сам: записывай только то, что человек сделал без твоей подсказки. «Задача без правок» значит: первый запрос дал приемлемый результат без переформулировки.

## Приватность, сброс, ошибки определения
- Файл лежит в домашней папке человека (`~/.ai-mentor-card.md`), не в репозитории. В карточку не попадают текст задач из Jira и Confluence, код, имена; только уровень по темам, слабое место и следующий шаг.
- Корпоративная память агента (если она есть) может читаться администратором: не клади карточку туда.
- Человек видит, что записано (`mentor.py status`, карточка целиком), и стирает всё словом «сбрось».
- Уровень в карточке не приговор: если человек говорит «это неверно» или явно сильнее записи, исправь запись сразу. Признаки пересмотра: повторяющиеся «дай ответ» без попытки (снижай глубину подсказок), задачи без правок постановки (повышай уровень).
