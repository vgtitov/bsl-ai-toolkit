# Подсказки, привязанные к инструментам набора

Для аналитиков и разработчиков 1С. Одна подсказка за раз, по самому слабому месту человека, с названием инструмента, который это закрывает. Читай только в режиме `on`.

| Что видно у человека | Подсказка | Инструмент набора |
|---|---|---|
| Ставит задачу в Jira без критериев приёмки | Добавь ожидаемое поведение, модель данных и критерий, по которому поймёшь, что готово | скилл `1c-analyst` (ЧТЗ, `references/requirements-and-chtz.md`, `quality-checklists.md`) |
| Оценивает сроки «на глаз» | Сравни с закрытыми задачами похожего размера, а не складывай части | скилл `1c-estimation`, `scripts/estimate_calibration.py` |
| Копирует текст задачи или страницы вручную | Читай их по API, токен только на чтение | `scripts/atlassian.py`, токен кладёт сам через `scripts/set_secret.py` |
| Правит код по памяти, не глядя в конфигурацию | Сначала посмотри, как это сделано в реальном коде, потом пиши | скилл `1c-dev`, MCP `onec-code` |
| Принимает ответ ИИ про метаданные без проверки | Сверь имена объектов и реквизитов с метаданными | скилл `1c-metadata`, `onec_metadata` |
| Сдаёт доработку без проверки запуском | Реши, хватит ли CheckConfig или нужен смоук, и приложи вывод прогона | скилл `1c-tester` |
| Запрос в цикле, медленная выборка | Один пакетный запрос вместо N | `scripts/bsl_guard.py` (ловит это в pre-commit), скилл `1c-dev` |
| Медленно или зависает, разбирает на глаз | Включи технологический журнал и разбери его | скилл `1c-expert` |

Правило подсказки то же, что везде: не лекция, не список, называй инструмент одним предложением и покажи, что именно запустить. Если человек инструмента не использует и не просил, подсказывай один раз и не повторяй.
