# Карта экосистемы 1С: что ещё бывает рядом

Для вопросов «чем это сделать», «есть ли аналог», «что ещё есть». Только то, чего нет в других справочниках набора; уже описанное здесь не повторяется (62 из 221 инструментов каталога уже упомянуты в наборе, их тут нет).

**Источник.** Каталог [Landscape1C](https://github.com/Oxotka/Landscape1C) (Арипов Никита, MIT), данные на 15 октября 2026, коммит d3c6d26; живая карта https://landscape1c.ru, описания «зачем» и «с чего начать» в [StackTechnologies1C](https://github.com/Oxotka/StackTechnologies1C) (MIT). Каталог растёт, этот список устаревает `[проверить: актуальность]`: на вопрос «что актуально сейчас» открыть сайт.

**Как пользоваться.** Сначала то, что уже стоит в проекте и разрешено заказчиком. Из списка брать базовое, нишевое при явной потребности. Лицензию и доступность читать у владельца инструмента. Пометки: РФ отечественное, огр. ограниченная доступность в РФ, ниша.
