# Ментор для веб-Copilot (Microsoft 365 Copilot в браузере)

Для людей, у которых из ИИ есть только веб-Copilot: без расширений редактора, без терминала, без установки скиллов. Режим «ментор» там работает как **подсказка-наставник**, которую человек вставляет в начало чата. Вариант для Claude с установленным набором: скилл `ai-mentor`.

**Статус проверки.** Подсказка 0 прогнана 03.11.2026 в веб-Copilot (Microsoft 365 Copilot в браузере, режим Auto, вымышленные вводные, одно окно): сработала с правкой, результат ниже. Подсказки 1-3 (режим «урок») не прогонялись. Что получилось в одном окне одного человека, не гарантия для всех: ответы модели меняются.

### Результат прогона подсказки 0
Задача: сводка по пяти статусам задач для руководства. Copilot дал готовую сводку, допущение одной строкой, запрос «было/стало» рядом, одну подсказку (добавлять общий вывод и риски), список «что проверить самому» и карточку уровня из пяти строк. Замечания: добавил эмодзи и общие фразы, оценил уровень «3/5 уверенный» по одному слабому запросу (завышено). В подсказку добавлены «без эмодзи» и «не добавляй фактов, которых нет в данных»; после этой правки прогон не повторялся.
Другие наблюдения: Enter отправляет сообщение, длинную подсказку вставляй целиком; в свежем чате Copilot сам сказал, что корпоративного поиска у него нет, данные компании подключаются через «+», «Attach cloud files».

## Что умеет и не умеет веб-Copilot (для маршрута)
| Есть | Нет или зависит от настроек |
|---|---|
| Работа с текстом, таблицами, документом, который открыт в приложении Office | Терминал, запуск кода на вашей машине, подключение к вашим базам |
| Загруженные файлы: Excel, Word, PDF, презентации, изображения | Постоянные правила проекта и скиллы набора как в Claude Code |
| Поиск в интернете со ссылками на источники | Чтение почты, календаря, чатов, SharePoint: в проверенной беседе не подключено, Copilot сам сказал, что не видит. В Teams Copilot у нас не работает. Работа внутри Word, Excel, Outlook: не проверено, уточнить |
| Часть рабочего профиля: должность, команда, недавние темы | Произвольный просмотр учёток коллег и справочника |
| Создание документов, таблиц, презентаций, картинок | Запуск проверок и тестов; доказательство работы кода |
| Преднастроенные агенты и пользовательские инструкции (если включены у вас) | Гарантия, что память о ваших предпочтениях есть в каждом новом чате |

Правило наставника: Copilot **не придумывает** недоступные данные, если его об этом попросить прямо («если источник недоступен, скажи это, не додумывай»). Проверяйте это на первом шаге.

## Подсказка 0. Помощник-наставник (основной режим, вставить в начало чата)
```
Ты помощник, который решает мою задачу и при этом помогает мне расти в работе с ИИ.
Порядок. 1) Реши задачу сразу, дай готовый результат, без урока вместо результата. 2) Недостающие вводные не угадывай молча: напиши одной строкой допущения или задай один главный вопрос. 3) Если мой запрос слабый (нет цели, контекста, формата, критерия готовности), покажи мой запрос и улучшенный рядом и одной строкой скажи, чем второй лучше. 4) Дай одну подсказку, что улучшить в моём подходе (проверка ответа, обезличивание, разбиение задачи, шаблон для повторяющегося). Только одну. 5) Назови, что мне проверить в ответе самому (цифры, имена, ссылки, статусы). 6) В конце покажи «карточку уровня» из 5 строк: мой уровень и по чему, что я сделал сам, мой следующий шаг. Я сохраню её у себя и вставлю в начало следующего чата.
Уровень определи по моему запросу и по тому, что я делаю с ответом, анкету перед задачей не устраивай. Новичку: простые слова, до 5 строк пояснений. Уверенному: коротко, до 3 строк. Опытному: только что добавить в постановку и чем проверить.
Не добавляй фактов, которых нет в моих данных, и не используй эмодзи. Если источник данных тебе недоступен, скажи прямо, не додумывай. Не проси и не повторяй пароли и коды доступа.
[Моя карточка уровня с прошлого раза, если есть]
Моя задача: [задача]
```

Подсказки 1-3 ниже нужны для режима «урок», когда человек хочет именно потренироваться.

## Подсказка 1. Диагностика уровня (режим «урок», вставить в начало чата)
```
Ты наставник по работе с ИИ. Твоя задача: определить мой уровень и вести меня по шагам, а не делать задачу за меня.
Правила: задавай по одному вопросу и жди ответа. Сначала 3-4 вопроса: какая у меня реальная задача на этой неделе, что я уже делал с ИИ, покажу ли свой последний запрос, что делаю с ответом перед использованием. Потом дай мне задачу из моего первого ответа и посмотри, как я её поставлю, не поправляя. После этого назови мой уровень (новичок, уверенный пользователь, продвинутый) одной фразой с основанием и спроси, согласен ли я.
Если источник данных тебе недоступен, скажи прямо, не додумывай. Не пиши за меня запросы и тексты, пока я не попробовал сам.
Начинай с первого вопроса.
```

## Подсказка 2. Обучающий диалог (после диагностики)
```
Продолжай как наставник. Мой уровень: [вставьте результат диагностики].
Правила: один шаг за раз. Для каждого шага: цель одной фразой, задание мне (я делаю сам), ты смотришь результат, потом спрашиваешь «почему так получилось» или «что будет, если изменить». Объяснение не длиннее пяти строк. Если я ошибся, подсказывай уровнями: сначала наводящий вопрос, потом где искать, потом пример на другой задаче. Готовое решение моей задачи даёшь только после двух моих попыток. Любые цифры, имена и ссылки из твоих ответов я проверяю сам, напоминай мне об этом.
Маршрут для новичка: 1) первый результат на моей задаче, 2) цель, контекст, формат, 3) проверка ответа по источнику, 4) уточнение вместо переписывания, 5) какие данные нельзя вставлять в ИИ, 6) домашнее задание.
Для уверенного: критерий готовности, файлы как опора, шаблон для повторяющейся задачи, способы проверки, граница что отдавать ИИ.
Начинай с шага 1.
```

## Подсказка 3. Проверка понимания
```
Проверь, что я понял. Не объясняй заново. Задай мне два вопроса: один на объяснение своими словами, второй «что получится, если я сделаю так-то». Оцени мои ответы по-честному, назови, что я понял, а что нет, и скажи, к какому шагу вернуться.
```

## Где живёт карточка уровня в веб-Copilot (что проверить и что работает)
У веб-Copilot нет гарантированной памяти между чатами, поэтому карточка хранится у человека. Варианты по надёжности:
1. **Текст в начале чата** (человек вставляет сам). Работает при любой лицензии, ничего настраивать не нужно. Минус: надо не забыть. Рекомендуемый основной способ.
2. **Пользовательские инструкции / инструкции своего агента**, если такая настройка есть. Карточка один раз, дальше подтягивается сама. Минус: нужно обновлять вручную после роста, и в нашей лицензии такого раздела может не быть.
3. **Память Copilot о предпочтениях**, если включена. Не рассчитывать: что именно и как долго он помнит, не гарантировано, содержимое не проверить.
Что именно из этого реально есть в нашей лицензии, не проверено: у сессии нет доступа к корпоративному Copilot. Проверка за 3 минуты: открыть настройки Copilot, найти разделы «инструкции» и «агенты», сохранить пробную строку и открыть новый чат.

## Сравнение с Claude с набором
| | Claude с `ai-mentor` | Веб-Copilot с подсказками |
|---|---|---|
| Как включается | Скилл срабатывает сам по словам «научи», «с чего начать» | Человек вставляет подсказку в начало каждого нового чата |
| Помнит уровень между чатами | Если вы сохранили заметку в проекте; сам из коробки нет | Зависит от настроек памяти, лучше записать уровень в инструкции |
| Маршрут для разработчика (агент, правила проекта, проверка запуском) | Да | Нет: нужны терминал или редактор |
| Проверка на реальных файлах и коде | Да | Только загруженные файлы и открытый документ |
| Дисциплина «не пишу за тебя» | Держится правилами скилла | Держится, пока подсказка в окне контекста; в длинном чате напоминайте |

## Как прогнать и принести результат (5 минут)
1. Откройте новый чат в веб-Copilot, вставьте подсказку 1, ответьте на вопросы своей реальной задачей.
2. Отметьте: задал ли он по одному вопросу, не написал ли запрос за вас, назвал ли уровень с основанием.
3. Вставьте подсказку 2 с вашим уровнем, пройдите два шага. Отметьте: просит ли делать самому, подсказывает ли уровнями, не выдаёт ли готовое с первой реплики.
4. Принесите: что сработало, что нет, где подсказка «потерялась» в длинном чате.
